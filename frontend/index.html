How to play

The goal is to fill every cell of the grid with either X or Y. When filled, the grid must follow these rules:

  1. Each row and column contains the same amount of X and Y.
  2. No more than two X or Y can be adjacent, either vertically or horizontally.
  3. If two cells have ‘=’ between them, they must contain the same symbol.
  4. If two cells have ‘╳’ between them, they cannot contain the same symbol.

There's only one solution. By following these rules, you can solve the puzzle; No guessing necessary.
